# 더 커피 프랜즈 상세페이지

index.html을 브라우저로 열면 바로 작동합니다. 설치나 서버가 필요 없는 로컬 시안입니다.

- index.html: 상품명, 본문, 이미지 경로, 문의 링크
- styles.css: 색상, 글꼴, 크기, 간격, PC·모바일 배치
- script.js: 다섯 캐릭터의 소개 문구와 탭 전환, 지도 이미지 확대
- assets/: 캐릭터·드립팩·포장 콘셉트 이미지와 커피 연출 이미지

캐릭터 탭은 클릭 및 좌우 방향키로 전환됩니다. 팩 선택 시 해당 친구의 이야기로 이동합니다. 상자 이미지를 클릭하면 확대됩니다. 공식몰과 전화 문의는 실제 외부 경로로 연결됩니다. 결제·주문 접수 기능은 없습니다.

모든 시각 자산은 임시 AI 생성 시안입니다. 인쇄 원본과 실제 제품 사진을 받으면 assets 파일과 HTML 경로를 교체하세요. 커피 연출 이미지도 생성 이미지이며 실제 제품 사진이 아닙니다.

확정 필요: 최종 구성 수량·가격·원두·풍미·필터 사양·배송·맞춤 제작 조건·포장 규격. 현재는 이를 임의 확정하지 않고 별도 안내로 표시했습니다. 캐릭터 이야기의 관광 순서는 실제 추천 이동 동선이 아닙니다.

커피 연출 이미지 생성 프롬프트 요약: 기존 다섯 원형 팩의 인쇄 디자인 유지, 밝은 바다 블루 배경, 오른쪽에 다섯 팩과 유리잔 블랙커피, 왼쪽은 HTML 제목용 여백, 밝은 자연광의 제품 사진. 내장 이미지 생성 도구 사용.
